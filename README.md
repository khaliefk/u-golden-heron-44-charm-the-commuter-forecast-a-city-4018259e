# Charm the Commuter: Forecast a City That Isn't

One line of weather, 140 characters at most, for a city that does not
exist, written to make a bored commuter smile on the way to work.

Bounty: https://make.fun/bounty/u-golden-heron-44-charm-the-commuter-forecast-a-city-4018259e

## The entry

> In Umbrella Falls, light rain, 14 degrees. The drizzle falls upwards today, so commuters reach work dry, suspicious, and five minutes early.

140 characters. Umbrella Falls does not exist. The forecast keeps the
shape of a real broadcast line, city first, then the weather, then the
twist: the drizzle falls upwards, so the morning commute goes better
than any commuter trusts it to go.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` and prints it with its
character count. The output is fixed, so every run writes the same
bytes.
